Design & Analysis of Algorithms Interactive Lab

Every benchmark execution on this page is transmitted to our native C backend (campus_server.exe) via REST API and executed using manual algorithm implementations. Hardware performance counters (QueryPerformanceCounter) report real microsecond durations.

Algorithm A: Merge Sort

Divide & Conquer

Handcrafted recursive sorting for complaints by Priority, Submission Timestamp, or ID with deterministic tie-breaking.

Best Case:O(n log n)
Average Case:O(n log n)
Worst Case:O(n log n)
Auxiliary Space:O(n)

Algorithm B: Binary Search

Divide & Conquer

Iterative binary search on records sorted strictly by Complaint ID. Cuts search space in half each comparison.

Best Case:O(1)
Average Case:O(log n)
Worst Case:O(log n)
Auxiliary Space:O(1)

Algorithm C: Max-Heap

Priority Queue

Binary Max-Heap for urgent dispatch. Peek root in O(1). Built in linear O(n) via Floyd's bottom-up algorithm.

Peek Max:O(1)
Insert / Extract:O(log n)
Floyd's Build:O(n)
Storage:O(n)

Algorithm D: Linear Search

Baseline Scan

Iterative baseline scan used to verify Binary Search correctness and demonstrate O(n) vs O(log n) scaling.

Best Case:O(1)
Average Case:O(n)
Worst Case:O(n)
Auxiliary Space:O(1)
